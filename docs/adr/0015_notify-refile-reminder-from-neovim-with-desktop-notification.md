# ADR: refile.org への促しは Neovim の中で数え、エディター内の通知とデスクトップ通知で知らせる

PRD 0009 の促しを Neovim の設定の中に Lua で自前実装し、エディター内の通知に加えて、macOS と WSL ではデスクトップ通知も出すという決定を記録する。

- 読者: 開発者
- 状態: 採用
- 決定日: 2026-10-04

用語は PRD 0009 と同じ意味で使う。
`refile.org`、促し、一時停止、導入範囲「すべて」「最小限」の意味は PRD 0009 による。
エディターは、ADR 0002 で既定エディターにした Neovim を指す。
デスクトップ通知は、OS が画面の隅に出す通知を指す。

## 背景

所有者は、作業中に考えたことを `refile.org` に書かないまま忘れてしまう。
意思の力で書こうとしても続かない。

PRD 0009 は、15分ごとに通知で促す案（案A）を採った。
案Aの通知は無視できるため、最後には意思の力に頼る。

促しをどこで動かし、通知をどこに出すかは決まっていない。

## 制約

PRD 0009 から、選べる案は次の条件を満たす必要がある。

- エディターを複数開いているときは、エディターごとに別々に数えて通知する。
- `refile.org` の見出しが増えると、15分を数え直す。`refile.org` を直接開いて書いた場合も数え直す。
- 通知は、所有者が閉じるかメモを書くまで残る。
- 1回の操作で、日時付きの見出しを書く入力欄が開く。
- 開発環境を「すべて」と「最小限」のどちらの範囲で導入しても、すべての要求を使える。
- 所有者のマシンだけに提供する。
- エディター以外で作業しているときに促すことは、PRD 0009 の対象外とする。

## 決定

促しは、Neovim の設定の中に Lua で自前実装する。
15分は、Neovim 組み込みのタイマーで数える。
新しいプラグインや、Neovim の外のプロセスは加えない。

通知は、エディターの中に出し、同時にデスクトップ通知も出す。
デスクトップ通知は、次の手段で出す。

- macOS: `osascript` の `display notification`
- WSL: `powershell.exe` から、Windows のトースト通知

## 決定理由

- タイマーを Neovim の中に置けば、エディターごとに数える仕様を、起動したエディターごとにタイマーを持つだけで満たせる。
- 同じく Neovim の中にあれば、`refile.org` の見出しが増えたことを Neovim の中で知り、15分を数え直せる。
- デスクトップ通知を出せば、ブラウザーなど別のウィンドウで作業していても、促しに気付ける。
- 案Aの通知は無視できるため、目に入る範囲を広げて、見落としを減らす。
- `osascript` は macOS に標準で入っている。`powershell.exe` からトースト通知を出す方法は、Windows の側に追加の導入がいらない。

## 代替案

次の案は、それぞれの理由で採らない。

- リマインダー用の既存プラグインを入れる案: 15分の数え直しやエディターごとの数え方に合わせる設定が要り、依存も増える。
- systemd timer や launchd など、Neovim の外のプロセスから通知する案: Neovim の外で時間を数えると、メモで数え直す仕様やエディターごとに数える仕様を満たしにくい。
- エディターの中だけに通知する案: 別のウィンドウで作業しているときに気付けない。
- デスクトップ通知だけにする案: 閉じるまで通知が残るという要求と、1回の操作で入力欄を開くという要求を満たせない。
- macOS で `terminal-notifier` を使う案: 追加の導入が要る。
- WSL で `wsl-notify-send` を使う案: Nix の外で、Windows の側に追加の導入が要る。

## 結果

- Neovim が起動している間は、ほかのアプリで作業していてもデスクトップ通知が目に入る。PRD 0009 の対象外に一部重なるが、Neovim が起動している間に限るため PRD 0009 の範囲内と解釈し、PRD 0009 は改めない。
- デスクトップ通知は、閉じるまで残るという要求を満たさない。この要求は、エディター内の通知で満たす。
- Linux ネイティブの環境では、デスクトップ通知を出さず、エディター内にだけ通知する。
- OS ごとに通知の出し方を分けて保守する必要がある。
- WSL では `powershell.exe` の起動に時間がかかるため、エディターの操作を止めないように非同期で呼ぶ。
