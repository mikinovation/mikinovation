# PRD: 受信箱への定期的なメモの促し

所有者が、作業中に考えたことや気付きを受信箱に書かないまま忘れてしまう課題について、時間をかけて取り組むべきかを判断するための問題と仮説を定める。

- 読者: 開発者
- 段階: 1. 出発点（問題と仮説を記録した。要求と受入条件は未着手）

この PRD の用語は次の意味で使う。

- 受信箱: 分類前のメモやタスクをいったん置くファイル。PRD「ノートとタスクの管理」（`docs/prd/0006_note-taking.md`）で定める。
- 促し: 一定の間隔で、所有者に受信箱へメモを書くよう求めること。

## 課題

### 問題と根拠

所有者は、受信箱を1回の操作で開ける（PRD 0006 の要求8）。
それでも、作業中に考えたことや気付きを受信箱に書かないまま忘れてしまう。

この問題は仮説であり、検証していない。
書き忘れたことを示す具体的な出来事は、まだ記録していない。

### なぜ今か

受信箱の運用が PRD 0006 で整った。
次の段階として、受信箱に書く習慣をつけたい。

### 対象となる利用者

リポジトリの所有者本人だけを対象とする。

### 仮説

- 15分ごとに促されれば、受信箱に残るメモの件数が増える。
- 15分ごとに作業を中断されても、作業の効率は落ちない。

## 未解決の問い

- 書き忘れはどのくらいの頻度で起きていて、それによって何を失っているか。段階2で確かめる。

## 出典

- 所有者の依頼（2026-10-04）: 15分ごとにエディターの受信箱へメモを書くことを強制したい
- 所有者へのヒアリング（2026-10-04）: 問題と根拠、なぜ今か、対象となる利用者、仮説、未解決の問い
- PRD「ノートとタスクの管理」（`docs/prd/0006_note-taking.md`）: 受信箱の定義、受信箱を1回の操作で開く要求
