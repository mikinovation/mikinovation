# PRD: 受信箱への定期的なメモの促し

所有者が、作業中に考えたことや気付いたことを取りこぼさずに受信箱へ残せるよう、15分ごとにメモを書くことを強く促す仕組みを検討するための課題を定める。

- 読者: 開発者
- 段階: 1. 出発点（課題と仮説を記録した段階。要求と受入条件は未着手）

この PRD の用語は次の意味で使う。

- 受信箱: 分類前のメモやタスクをいったん置くファイル。PRD「ノートとタスクの管理」（`docs/prd/0006_note-taking.md`）で定める。
- エディター: PRD 0002「エディターの導入」で導入するエディター。
- 促し: 一定の間隔で所有者にメモを書くよう求めること。
- 強制: 促しを所有者が無視したまま作業を続けられないようにすること。どこまで妨げるかは未解決の問いとする。

## 課題

### 問題と根拠

所有者は、受信箱を1回の操作で開ける状態にある（PRD 0006 の要求8）。
しかし、受信箱を開くかどうかは所有者の注意に任されている。
作業に集中していると、考えたことや気付いたことを受信箱に書かないまま時間が過ぎる、と所有者は考えている。

この根拠は所有者の依頼に基づく仮説であり、書き忘れの頻度や、それによって何を失ったかは検証していない。

### なぜ今か

所有者が、15分ごとに受信箱へメモを書くことを強制したいと依頼した（2026-10-04）。
これより前の時点で取り組まなかった理由と、今取り組む理由は、未解決の問いとする。

### 対象となる利用者

リポジトリの所有者本人だけを対象とする。

### 仮説

- 15分ごとに促されれば、所有者は作業中の考えを受信箱に書き残すようになる。
- 促しを無視できない形にすると、無視できる通知よりも書き残す回数が増える。
- 15分ごとに作業を中断しても、書き残したメモの価値が中断の損失を上回る。

## 未解決の問い

- 書き忘れによって、実際に何を失っているか。
- 「強制」とは、通知を出すことか、受信箱を自動で開くことか、メモを書くまで他の操作をさせないことか。
- エディターを開いていないとき、またはエディター以外で作業しているときにも促すか。
- 会議中や集中したい作業の最中など、促しを止めたい場面があるか。止める場合、どう止めるか。
- 15分という間隔の根拠は何か。間隔を変えられる必要があるか。
- メモを書いたとみなす条件は何か。受信箱を開いただけでよいか、1件の見出しを追加する必要があるか。
- 何をもって効果があったと判断するか。
- なぜ今取り組むのか。
- 開発などの関係者の意見を、課題を確定させる前に集めたか。対象が所有者本人だけのため、不要としてよいか。

## 出典

- 所有者の依頼（2026-10-04）: 15分ごとにエディターの受信箱へメモを書くことを強制したい
- PRD「ノートとタスクの管理」（`docs/prd/0006_note-taking.md`）: 受信箱の定義、受信箱を1回の操作で開く要求
